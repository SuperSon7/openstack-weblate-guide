=============================
OpenStack Weblate walkthrough
=============================

This repository contains a draft guide for translating with OpenStack
Weblate. It is shared for discussion and revision, with the writing style
and heading conventions of the OpenStack I18n Contributor Guide in mind.

Read the `illustrated draft <doc/source/openstack-weblate-guide.rst>`_
or download the `HTML preview <openstack-weblate-guide.html>`_ for offline
reading. The guide is written in English and uses a Korean translation as
its example. Eleven annotated screenshots show the workflow from sign-in
to checking a saved translation.

Feedback is welcome on the section order, wording, terminology, and
screenshots. Open an issue or propose an edit to discuss a change.
